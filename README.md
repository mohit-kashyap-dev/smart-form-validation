# ✅ Smart Form Validation System

A React-based form validation system using Formik and Yup with real-time error handling.

---

## 🚀 Features

- Real-time validation
- Schema-based validation using Yup
- Form handling with Formik
- Responsive UI with Material UI

---

## 🛠️ Tech Stack

- React.js
- Formik
- Yup
- Material UI
- JavaScript
